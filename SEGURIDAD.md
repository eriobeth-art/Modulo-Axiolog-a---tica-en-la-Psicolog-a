# Seguridad del paquete GitHub

Este repositorio público NO contiene la clave docente de desbloqueo.

La clave se mantiene exclusivamente en el backend de Google Apps Script.

No subas a GitHub:
- `Code.gs`
- el ZIP del backend
- copias del backend que contengan `CLAVE_DOCENTE`

El modo supervisado registra eventos del navegador (visibilidad/foco) y aplica advertencia/bloqueo. No debe describirse como un sistema de proctoring invulnerable.

La calificación oficial se calcula nuevamente en el backend para no depender de respuestas correctas expuestas en el código público.
